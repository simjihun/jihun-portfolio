15×15 바둑판에서 AI와 1:1 대국합니다. 원하는 돌 색과 난이도를 고르고 시작하세요. 가로·세로·대각선 어느 방향으로든 먼저 5목을 이으면 승리입니다. AI는 외부 API 없이 서버에서 직접 계산하는 알고리즘(패턴 평가 + 미니맥스)으로 동작해 응답이 즉각적입니다.

대국 설정

-

1~9 중복 없는 숫자 4자리를 서버가 무작위로 정해두면, 여러분이 추리해서 맞히는 게임입니다. 숫자와 자릿수가 모두 일치하면 스트라이크(S), 숫자만 일치하면 볼(B)입니다. 최소 시도 횟수로 맞히면 랭킹에 이름을 올릴 수 있어요.

9×10 궁성이 있는 전통 장기판에서 AI와 1:1 대국합니다. 진영과 포진을 고르고 시작한 뒤, 기물을 클릭하면 이동 가능한 칸이 초록색으로 표시됩니다 — 그 칸을 다시 클릭하면 이동합니다. 직전 수(내 수·AI 수 모두)는 주황색 테두리로, 장군 상태는 장군을 부른 쪽의 색(한=빨강/초=파랑)으로 보드 테두리와 궁 칸이 함께 깜빡이며 표시됩니다. AI는 외부 API 없이 서버에서 직접 계산하는 알고리즘(기물 가치 평가 + 알파베타 완전탐색)으로 동작하며, 사람 수가 반영된 뒤 잠깐(약 1초) 뜸을 들이고 응수합니다. 병(졸)의 궁성 대각선 이동만 간소화를 위해 생략했습니다.

대국 설정

-

오리지널 캐릭터 몽이로 AI와 실시간 비치발리볼 대결을 합니다. ←→(또는 A/D)로 이동, 스페이스바(또는 ↑)로 점프해서 공을 상대 코트로 넘기세요. 공이 자기 쪽 바닥에 닿으면 상대가 득점하며, 먼저 5점을 내면 그 판은 승리입니다. 이기면 곧바로 다음 상대와 이어서 붙어 연승 기록에 도전할 수 있고, 지는 순간까지의 연승 수가 최종 기록으로 랭킹에 남습니다. 난이도 선택 없이 AI가 공의 낙하 지점을 미리 예측해 움직이는 상당히 까다로운 상대로 고정되어 있습니다. 중력·충돌·반사 같은 물리 연산은 서버 왕복 없이 브라우저에서 매 프레임(Canvas + requestAnimationFrame) 직접 계산합니다.
