9×10 궁성이 있는 전통 장기판에서 AI와 1:1 대국합니다. 진영과 포진을 고르고 시작한 뒤, 기물을 클릭하면 이동 가능한 칸이 초록색으로 표시됩니다 — 그 칸을 다시 클릭하면 이동합니다. 직전 수(내 수·AI 수 모두)는 주황색 테두리로, 장군 상태는 장군을 부른 쪽의 색(한=빨강/초=파랑)으로 보드 테두리와 궁 칸이 함께 깜빡이며 표시됩니다. AI는 외부 API 없이 서버에서 직접 계산하는 알고리즘(기물 가치 평가 + 알파베타 완전탐색)으로 동작하며, 사람 수가 반영된 뒤 잠깐(약 1초) 뜸을 들이고 응수합니다. 병(졸)의 궁성 대각선 이동만 간소화를 위해 생략했습니다.

대국 설정

-

오리지널 강아지 캐릭터 몽이로 AI와 실시간 비치발리볼 대결을 합니다. ←→(또는 A/D)로 이동, 스페이스바(또는 ↑)로 점프해서 공을 상대 코트로 넘기세요. 대결 전 총 라운드 수(10/20/30판)를 정해두고, 그 라운드를 모두 마치면 승패와 무관하게 대결이 끝나며 최종 스코어(예: 7:13)가 랭킹에 남습니다. 대결 시작 전 5→1 카운트다운, 매 라운드 사이에도 3→1 카운트다운이 있어 갑자기 실점하는 일이 없습니다. 난이도 선택 없이 AI는 항상 공의 낙하 지점을 미리 예측해서 움직이는 상당히 까다로운 상대입니다. 중력·충돌·반사 같은 물리 연산은 서버 왕복 없이 브라우저에서 매 프레임(Canvas + requestAnimationFrame) 직접 계산합니다.
