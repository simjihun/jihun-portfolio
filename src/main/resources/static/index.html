지도 API — 맛집 지도 · 부동산 시세

  • 현위치 검색 + 지도를 옮긴 뒤 "이 지역에서 재검색"
  • 아파트 실거래가를 단지별 좌표·가격으로 지도에 표시
  • 키워드 기반 지오코딩으로 건물명 인식률 개선
  • localStorage로 검색 결과·지도 위치를 세션 간 유지
